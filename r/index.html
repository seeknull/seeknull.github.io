OTP Relay request link

If OTP Relay is installed on this phone, this link opens the app and shows an approval prompt. Since you are reading this page instead, the app is not installed here.

This page is static. The request details travel in the part of the URL after the #, which browsers never send to the server, so nothing about the request reached this site or was recorded anywhere.

OTP Relay is an open source Android app that forwards one-time passcodes to one chosen number for a limited time. Source and installation instructions: github.com/seeknull/otp-relay
