# seeknull.github.io

Public static pages for repos in the seeknull org.

## Folders

| Path | Repo |
| --- | --- |
| `/r/` | [otp-relay](https://github.com/seeknull/otp-relay) |
| `/openwispr/` | [openwispr](https://github.com/seeknull/openwispr) — its own Pages site, served from that repo |

`.well-known/` and `.nojekyll` are shared. Leave them in place.

`index.html` lists every project (keep it in step with `branding/messaging.md`
in the seeknull.com repo). `sitemap.xml` lists the indexable pages on this
host, project Pages sites included; `/r/` is `noindex` and stays out of it.
